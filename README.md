Customer Churn Analysis & Retention Dashboard

Overview

An end-to-end Data Analytics project to analyze customer churn, identify churn drivers, and understand customer segments using Python, SQL, and Tableau.

Objectives

Analyze overall customer churn
Identify factors contributing to churn
Compare churn across contracts, services, payment methods, and customer segments
Analyze revenue loss and customer tenure
Build interactive Tableau dashboards for business insights
Tools & Technologies

Python: Pandas, NumPy, Matplotlib, Seaborn
SQL: MySQL
Visualization: Tableau
Dataset: IBM Telco Customer Churn Dataset
Dataset

7,043 customers
21 features
Target variable: Churn (Yes/No)
Analysis Performed

Python

Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Churn distribution and customer behavior analysis
SQL

Data cleaning
Aggregations and filtering
Customer churn analysis
Business-oriented SQL queries
Tableau

Created 3 interactive dashboards:

Executive Overview
Churn Drivers Analysis
Revenue & Customer Segments
Key Insights

Overall customer churn is approximately 26.5%
Churn varies across contract types and services
Customer tenure and monthly charges show differences between churned and retained customers
Certain payment methods and service combinations have different churn patterns
